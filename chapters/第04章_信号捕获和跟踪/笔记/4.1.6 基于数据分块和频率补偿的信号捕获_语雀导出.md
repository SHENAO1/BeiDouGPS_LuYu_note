这份材料介绍的是一种**基于数据分块（Data Partitioning）和频率补偿（Frequency Compensation）的GNSS（全球导航卫星系统）信号捕获方法**。

这种方法的核心思路是通过将多毫秒的连续数据进行“矩阵化”处理，利用两次不同维度的FFT（快速傅里叶变换）来同时提取多普勒频率和伪码相位，从而在保证捕获灵敏度的同时，大幅降低计算量。



---

### 1. 核心背景：为什么要分块？
在弱信号环境下，我们需要增加相干累加时间（即 $ L $ 毫秒数据）来提高信噪比（SNR）。但直接累加存在两个难题：

+ **载波相位不一致**：由于多普勒频移的存在，每一毫秒信号的起始相位都在旋转。直接相加会导致信号互相抵消（即材料中提到的增益函数 $ G(L, f) $ 会变小）。
+ **计算量巨大**：如果要对长达 $ L $ 毫秒的数据直接做高分辨率的频率搜索，FFT的点数会非常多，计算压力极大。



### 2. 算法的三大关键步骤
#### 第一步：数据分块与矩阵重排 (图4.20)
系统将接收到的 $ L $ 毫秒数据切割成 $ L $ 个数据块（每块 1ms）。

+ **横轴（行）**：每行代表 1ms 内的 $ N $ 个采样点。
+ **纵轴（列/竖块）**：将每个 1ms 块中**相同位置**的采样点抽出来，组成一个长度为 $ L $ 的序列。

> **巧妙之处**：由于伪码（PRN）是以 1ms 为周期重复的，所以纵轴方向上的 $ L $ 个点具有相同的伪码相位，它们之间唯一的差别就是由多普勒频率引起的**载波相位旋转**。
>



#### 第二步：纵向 FFT —— 频率补偿 (图4.21)
对每一个“竖块”（长度为 $ L $）进行 FFT 变换。

+ 这个操作相当于在频率域进行搜索。
+ 由于竖块采样点的间隔是 1ms，其等效采样率为 1kHz。
+ 通过纵向 FFT，可以精确地找到多普勒频移中偏离 1kHz 整数倍的那部分残余频率（$ \Delta f_k $）。
+ **物理意义**：这一步通过数学手段把原本相位不齐的 $ L $ 块信号“对齐”了。



#### 第三步：横向并行捕获 —— 伪码相位搜索 (图4.22)
在纵向 FFT 完成后，数据被补偿到了正确的频率上。

+ 此时再对每一行进行标准的**并行码相位捕获**（即：本地码 FFT $ \times $ 信号 FFT，再做 IFFT）。
+ 这样就能在二维平面上找到相关峰，从而确定卫星的 PRN 编号、多普勒频率和伪码起始位置。

---

### 3. 该方法的主要优势
+ **信噪比增益（SNR Gain）**：  
材料指出，通过这种相干累加，信号强度增大了 $ L $ 倍，信号功率增大了 $ L^2 $ 倍。虽然噪声功率也增大了 $ L $ 倍，但最终的信噪比提升了 $ 10\log_{10}L $ dB（例如 $ L=10 $ 时，提升 10dB）。
+ **计算效率极高 (图4.23)**：  
这是该方法最大的亮点。
+ **传统方法**：需要对 $ L \times N $ 个点做超长 FFT。
+ **分块方法**：将其分解为 $ N $ 个 $ L $ 点 FFT 和若干 $ N $ 点 FFT。
+ 根据公式 (4.84) 和 (4.85) 的对比，当 $ L $ 较大时，分块处理的运算量远小于常规 FFT 捕获（如图4.23中的曲线对比，运算量呈指数级下降）。
+ **搜索范围优化**：  
由于纵向处理解决了 1kHz 以内的精细频率搜索，本地载波只需要以 1kHz 为步长进行粗搜（例如覆盖 $ \pm 5 $kHz 只需要 10 个频率点），大大减少了搜索空间。

---

### 4. 总结
这种方法是一种“分而治之”的策略：**纵向 FFT 搞定频率偏移，横向并行搜索搞定伪码相位**。它特别适合硬件资源有限、但又需要捕获弱信号（需要长时积分）的 GNSS 接收机设计。

### 实信号频谱的冗余性如何理解？
实信号的频谱是共轭对称的，如果是一个实信号，那么必然有一对互为共轭的复信号在虚轴上的输出时刻相互抵消，所以才能保证只有实轴上有投影，所谓的<u>冗余就是负频率点=正频率点的共轭</u>。

设$ x[n] $是长度为$ N $的实序列，即有：$ x[n]\in \mathbb{R} $，其N点 DFT 定义为：  $ X[k]=\sum_{n=0}^{N-1}x[n]e^{-j\frac{2\pi}{N}kn} $

负频率索引$ -k $所对应的频谱为：$ X[-k]=\sum_{n=0}^{N-1}x[n]e^{-j\frac{2\pi}{N}(-k)n}=\sum_{n=0}^{N-1}x[n]e^{j\frac{2\pi}{N}kn} $

对$ X[k] $取共轭有：$ X^*[k]
=
\left(
\sum_{n=0}^{N-1}x[n]e^{-j\frac{2\pi}{N}kn}
\right)^*

=
\sum_{n=0}^{N-1}x^*[n]
\left(e^{-j\frac{2\pi}{N}kn}\right)^*

=
\sum_{n=0}^{N-1}x[n]e^{j\frac{2\pi}{N}kn} $

故有：$ X[-k]=X^*[k] $

但FFT的索引不是直接写$ -k $，而是写成$ 0,1,\dots,N-1 $，即DFT认为信号在时域和频域都是周期的。负索引要用模$ N $映射回来，有：$ -k \equiv -k+N \pmod N $

因此有：$ X[(-k)\bmod N]=X^*[k] $，共轭可以再取一次共轭，那么就有：$ X[k]=X^*[(-k)\bmod N] $

假设接收到的射频信号是：$ r(t) = A \cos(2\pi f_c t + \phi) $ ，其中 $ \phi $ 包含了需要的相位信息

+ **I 路（乘法后）**：

$ I(t) = A \cos(2\pi f_c t + \phi) \cdot \cos(2\pi f_c t) $

利用三角函数乘法公式 $ \cos(A)\cos(B) = \frac{1}{2}[ \cos(A+B)+ \cos(A-B) ] $：

$ I(t) = \frac{A}{2} [\underbrace{\cos(\phi)}_{\text{基带/低频}} + \underbrace{\cos(4\pi f_c t + \phi)}_{\text{两倍高频}}] $

+ **Q 路（乘法后）**：

$ Q(t) = A \cos(2\pi f_c t + \phi) \cdot (-\sin(2\pi f_c t)) $

利用公式 $ \cos(A)\sin(B) = \frac{1}{2}[\sin(A+B) - \sin(A-B)] $：

$ Q(t) = \frac{A}{2} [\underbrace{\sin(\phi)}_{\text{基带/低频}} - \underbrace{\sin(4\pi f_c t + \phi)}_{\text{两倍高频}}] $



混频后的信号里既有我们想要的低频部分（基带信号），也有一个两倍频率的高频部分。硬件在 I 路和 Q 路后面各接了一个**低通滤波器**。滤波器把那个“两倍高频”项直接滤掉，只剩下：$ I \approx \frac{A}{2} \cos(\phi) $，$ Q \approx \frac{A}{2} \sin(\phi) $



这里的**不是天线刚收到的射频原始信号**，它已经经过了射频前端的下变频、滤波、采样；但是还没有在捕获算法里完成本地载波频率补偿和 PRN 码相关。是**进入数字捕获算法之前的离散中频/基带等效采样信号**。实际接收机采样得到的是两路信号：

$ Q_k[n]=D_k[n]C_k[n]\sin(2\pi f_k nT_s)+v_Q[n] $

$ s_k[n]=I_k[n]+jQ_k[n] $

I\cos\theta+Q\sin\theta
+j(Q\cos\theta-I\sin\theta) $

 **因为旋转坐标以后，原来的 Q 分量也会投影到新的 I 轴上**。I 和 Q 不再是互不影响的，它们会按照旋转角度互相混合。

把这 L 个数据块的相同位置的对应样点进行叠加是因为每个数据块正好是1ms，且北斗、GPS等全球卫星定位导航系统的伪随机码周期也为1ms，如果这 L ms的数据分为了 L 个块，那么每个数据块对应位置的采样点数据位和伪码都是一样的。

假设已经对每个数据块中相同位置的采样点进行了频率补偿，那么L个数据块中相同位置的信号相加可以把幅值扩大 L 倍，信号功率增强$ L^2 $倍。

与此同时噪声是随机的，不同数据块中的噪声相互独立，在复平面上的方向也不同，如果噪声方差为$ \sigma^2 $，那么L个噪声相加后方差$ L\sigma^2 $，即噪声的功率只提高了L倍， 最终信噪比提升L倍，换成dB有$ 10\log_{10}L $，这就是对不同数据块的数据进行相干累加

> 利用伪随机码周期为1ms的特点，把多个周期中同一伪随机码相位的采样点相加，在载波频率完成补偿的前提下，根据噪声功率随数据块长度线性增加而信号幅度随数据块长度线性增加的特点，提高信噪比，进而提高捕获灵敏度
>
> 如果频率补偿不好，相干累加会变为相位抵消
>

> 对于一个均值为零（$ E[X] = 0 $）的随机噪声信号 $ X $，
>
> + **均值 (Mean):** 代表直流分量。通常噪声被建模为零均值
> + **方差 (Variance):** 计算公式为 $ Var(X) = E[X^2] - (E[X])^2 $，从**统计学角度上看**衡量噪声波动的幅度大小（离散程度），**物理/工程角度：** 衡量噪声中包含的能量。
> + $ \sigma $（标准差）通常代表噪声的**有效值 (RMS)**，即电压或电流的物理幅度。
> + **平均功率 (Average Power):** 定义为信号平方的期望值，即 $ P = E[X^2] $
>
> 当均值为零时：$ \sigma^2 = E[X^2] = \text{功率} $。
>



把这L个数据块的相同位置对应样点进行叠加，有式4.66，这里用到了特别重要的一个有限长复指数求和，也叫狄利克雷核，在利用FFT进行频谱分析时，这相当于是矩形窗的频率响应。因为对L个数据块中的相同位置的采样点进行相加，相当于在块序号方向上乘上了一个长度为L的矩形窗（书中这里就是竖向）

令$ T_b=NT_s $，因为每个数据块均为1ms，则有$ T_b=NT_s=1\text{ ms} $，原式为：

$ G(L,f_k)=\sum_{i=0}^{L-1}e^{j2\pi f_k iNT_s} $

是公比为：$ q=e^{j2\pi f_kNT_s} $的等比数列。如果$ q=e^{j2\pi f_kNT_s}\neq 1 $，则根据等比数列的求和公式有：$ G(L,f_k)=\frac{1-e^{j2\pi f_kLNT_s}}{1-e^{j2\pi f_kNT_s}} $，分子分母同时提出对应复指数的一半，通过欧拉公式凑sin的表达式有：

$ G(L,f_k)
=
e^{j\pi f_k(L-1)NT_s}
\frac{\sin(\pi L f_kNT_s)}{\sin(\pi f_kNT_s)} $

其幅度为：

$ |G(L,f_k)|
=
\left|
\frac{\sin(\pi L f_kNT_s)}{\sin(\pi f_kNT_s)}
\right| $

如果有：$ e^{j2\pi f_kNT_s}=1 $，即$ f_kNT_s \in \mathbb{Z} $，那么每一项都是1，求和就是L：$ G(L,f_k)=1+1+\cdots+1=L $，此时的相位差都是0，处于最理想的完全相干叠加的状态。那么由$ NT_s=1\text{ ms} $， 条件变成：$ f_k\cdot 1\text{ ms}\in \mathbb{Z} $

故：$ f_k = 0,\ \pm 1\text{ kHz},\ \pm 2\text{ kHz},\cdots $所以当频率为1kHz的整数倍时，$ G(L,f_k) $取得最大值L，其中L是相干累加的点，即求和点数



$ f_kNT_s \in \mathbb{Z} $即代表不同采样点之间的相位差了整数圈，因为复指数的周期性又回到了相同的相位进行了完全同相的叠加，但也有可能不同采样点之间的相位没有这么完美，即不同采样点之间存在相位差，即$ |G(L,f_k)| $的分子为0而分母不为0时，增益为0，此时求和后狄利克雷核函数的模值为0，所有采样点因为相位差的原因求和正好抵消。即：

$ \sin(\pi L f_kNT_s)=0 $

根据正弦函数的性质有$ L f_kNT_s=m $，体现到频率上为：

$ f_k=\frac{m}{LNT_s} $

因为$ NT_s=1\text{ ms} $，所以$ f_k=\frac{m}{L}\cdot 1\text{ kHz} $。 第一个过零点大约在：  

$ f_k=\pm \frac{1\text{ kHz}}{L} $

即有累加的数据长度越长，那么对频率误差的就越敏感，频率搜索的步进（或者说频率补偿）就要更小，防止出现幅度为0（相关峰消失）的情况

因为跨数据块叠加只观察每隔$ T_{\text{block}} $秒的相位变化，所以频率相差$ 1/T_{\text{block}} $Hz时， 它们带来的相邻块相位差相差是$ 2\pi $，而$ 2\pi $在相位上等价于没变，那么在这些块起点上产生的相位序列完全相同。因此如果$ \Delta f_k $是优化补偿量，那么$ \Delta f_k+n/T_{\text{block}} $ 也是等效优化补偿量。 数据块长度为 1 ms 时，这个周期就是 1 kHz；数据块长度为 2 ms 时，周期就是 500 Hz。  并不是说真实多普勒频率本身有周期性。真实多普勒不是周期出现的，只是跨数据块相干叠加的角度看，系统只关心相邻数据块之间的相位变化，



 设每个数据块长度为：$ T_b=N t_s $， 经过频率补偿后，等效载波频率为：$ f_k' = f_k+\Delta f_k $， 那么第 i 个数据块相对于第 0 个数据块，在同一个块内采样位置上的相位多转了：$ 2\pi f_k' iT_b $， 所以块间累加因子是：$ G(L,f_k')=\sum_{i=0}^{L-1} e^{j2\pi f_k' iT_b} $， 要让 L 个数据块相干叠加最大，就希望每一项都同相，也就是$ e^{j2\pi f_k' T_b}=1 $， 这等价于$ f_k'T_b=m,\quad m\in\mathbb{Z} $，所以：$ f_k'=\frac{m}{T_b} $， 也就是补偿后剩余的载波频率必须是数据块频率的整数倍。 因为：$ f_k' = f_k+\Delta f_k $， 所以优化的补偿量满足：$ (f_k+\Delta f_k)T_b=m $，即$ \Delta f_k=\frac{m}{T_b}-f_k $，如果某个$ \Delta f_k $是优化值，那么：$ \left(f_k+\Delta f_k+\frac{q}{T_b}\right)T_b
=
(f_k+\Delta f_k)T_b+q $ 仍然是整数。  $ \Delta f_k+\frac{q}{T_b} $也是优化值，那么 所以优化后的$ \Delta f_k $会周期性出现，周期就是：$ \frac{1}{T_b} $（频率补偿的多或者少了，只要是使得相位转了$ 2\pi $的整数倍都可以达到最大相干增益）

从4.78可以看到，同一个竖块中的各个点，都可以写成竖块中第一个点的信号乘一个复指数；下一个横块中相同位置的点，就是竖块中的下一个点，由于选择1ms作为一个数据块，则$ T_b=N t_s=1ms $，如果把载波频率f_k分成1kHz的整数倍和余数部分，由于f_k N T_s=1，则采样点的形式可以简化。

对L个采样点进行FFT，还是会得到L个结果，4.80中的i表示数据块的编号，m表示谱线的编号，由于竖块中的点可以看做是采样率1kHz采样得到的，故谱线间隔是{f_p\frac}{L}，这里又是一个复指数等比级数求和，即狄利克雷核的形式。

此时相对于横块m中，一行数所对应的FFT中的旋转因子频率是相同的，旋转因子换成角频率形式有：$ \omega_m=\frac{2 \pi f_p}{L} m $，m只和数据位于第几个横块有关，和采样时刻无关，所以同一个横块m中，4.81中除去信号s(i)的部分A(m)是一个公共项，其取模后的幅值只和数据位于第几个横块有关









**为什么要对竖块数据进行FFT后重新排列呢？**

因为竖向的FFT是把多个1ms块压缩成了多个频率假设块；然后对每一个频率假设m，重新取出所有的横向位置i=0,...,N-1，组成一个新的1ms数据块。这个新数据块的横向仍然有N个点，相邻点对应的原始采样间隔为T_s



把每一个复采样点看做是IQ平面上的一根旋转小箭头，如果信号有残余载波频率时，这根箭头会随着时间不旋转，公式4.80与4.81就是每隔1ms取观察这些箭头，然后用FFT判断它们每1ms到底转了多少角度。



公式4.80就是用第m个候选频率去反向旋转这L个采样点，然后把他们加起来，看能不能对齐。如果$ \omega_m $正好等于$ \Delta\omega_k $，即当残余频率$ \Delta f_k $正好落在FFT第m根谱线上时，那么$ e^{j\Delta\omega_knNT_s}e^{-j\omega_mnNT_s}=1 $，每一项都会变成$ s(i) $，L个箭头方向完全一致，FFT后的结果为$ Ls(i) $。



$ \omega_m=\frac{2 \pi f_p}{L} m $，其中$ f_p=1\text{ kHz} $，第m个FFT谱线对应的频率是$ f_m=\frac{m}{L}f_p $，FFT把$ 0\sim1\text{ kHz} $ 的余频范围分成$  L $个候选频率点，每个m代表一个猜测频率。$ \omega_m $的频率粒度是1kHz被L等分，L越大，多普勒频率的分辨率就越高

例如取了$ L=10 $个数据块，每个数据块1ms，频率谱线间隔就是$ \frac{1\text{ kHz}}{10}=100\text{ Hz} $，FFT在竖块方向上的FFT相当于在同一个码相位上，同时测试$ 0,\ 100,\ 200,\ \cdots,\ 900\text{ Hz} $这些余频候选点



对每一个竖块做FFT，以第i个竖块为例，$ s(i),\ s(N+i),\ s(2N+i),\cdots,s((L-1)N+i) $。共有L个点，做L点FFT，得到：$ Y(i,0),Y(i,1),\cdots,Y(i,L-1) $，其中输入竖块的索引为i，FFT输出的频率索引为m，对每一个竖块i，会有一列的频率结果：

$ \begin{bmatrix}
Y(i,0)\\
Y(i,1)\\
\vdots\\
Y(i,L-1)
\end{bmatrix} $

这一列是在同一个码相位下的，不同频率索引的FFT结果。下一步就是重排，把同一个频率索引下的不同码相位的结果收集到一块，进行基于FFT的并行码相位捕获，做码相位捕获的时候需要保持频率索引（频率值）是相同的。 然后把所有$ i $的结果放到一起，就得到：  

$ \begin{bmatrix}
Y(0,0) & Y(1,0) & \cdots & Y(N-1,0)\\
Y(0,1) & Y(1,1) & \cdots & Y(N-1,1)\\
\vdots & \vdots & \ddots & \vdots\\
Y(0,L-1) & Y(1,L-1) & \cdots & Y(N-1,L-1)
\end{bmatrix} $

下一步是把同一个FFT频率索引的结果放在同一行，生成$ Y(0,m),Y(1,m),\cdots,Y(N-1,m) $，这里是m的含义是：<u>第m个残余频偏假设下</u>得到的<u>等效1ms</u>数据块，按照等效残余频率索引进行了重新分组。根据式4.81有$ Y(i,m)=s(i)A(m) $，其中$ A(m) $与i无关，第m个横块就可以写成：$ s(0)A(m),\ s(1)A(m),\ \cdots,\ s(N-1)A(m) $

所以$ Y(0,m),Y(1,m),Y(2,m),\cdots $在对应1ms码周期内相邻的两个采样位置，等效采样间隔仍然为T_s，横向上对应的采样位置仍然相隔T_s，

同时由于第m个横块中的数据是：$ s(0)A(m),s(1)A(m),\cdots,s(N-1)A(m) $，与原始的1ms数据$ s(0),s(1),\cdots,s(N-1) $相比只多了一个公共系数，且这个复系数对同一个横块是一个固定值，即这个公共系数不会改变伪码结构与1ms内的波形形状，且与采样时刻无关。

> 原来的L个1ms时间块，经过了竖向FFT后变为了L个频率谱线。固定某一个频率索引m后，把所有横向采样位置$ i=0,\cdots,N-1 $的$ Y(i,m) $取出来，就得到一个长度为N的等效1ms序列。由于$ Y(i,m)=s(i)A(m) $，其中$ A(m) $与i无关，只与所选的频率索引有关，每一行对应一个多普勒频率假设故这个序列在横向上仍然保持原始$ s(0),s(1),\cdots,s(N-1) $的采样结构，等效采样间隔为$ T_s $，且这个序列包含一个完整周期的伪码信号，因此可以继续做码相位捕获
>



竖块的FFT是看在这个位置上的信号，每隔1ms相位旋转了多少。主要是为了搜索余频：$ 0,\frac{1\text{ kHz}}{L},\frac{2\text{ kHz}}{L},\cdots,\frac{(L-1)\text{ kHz}}{L} $

> 竖向FFT在利用这些相位随1ms间隔的变化规律来搜索残余载波频率，在频率匹配时实现相干累加增益。FFT对多个候选频率做了反向旋转与相干累加，如果反向旋转抵消了真实旋转，那么就会产生很大的相干累加增益。同时用一次L点FFT并行得到了L个残余频率假设的累加结果。
>
> $ f_k=F\cdot 1\text{ kHz}+\Delta f_k $，竖块FFT只能确定1kHz以内的残余部分，即$ \Delta f_k $，整数F对应的是第几个1kHz频率区间，靠横块FFT捕获时设置的本地载波频率来区分
>



重排的原因是码相位搜索的时候需要保持残余频率（等效残余频率）一致，所以要把同一个频率索引下点收集到同一个模块里



整数F靠横块数据捕获时的本地载波频率档位确定，横块内部相邻采样点$ s(i),s(i+1),s(i+2),\cdots $的采样间隔是$ T_s $，所以1kHz的相位旋转不会每个采样点都刚好转整数圈，横向的时候可以通过FFT一次计算输出所有码相位的结果，如果频率对准了，那么就可以得到一个较大的相关峰，否则码相位对准了也是对一个带频差的正弦或者说余弦做积分，相关峰的值会很低甚至接近为零。所以可以看到$ F\cdot1\text{ kHz} $造成的相位斜率





竖块FFT对应的是找到残余频偏，横块FFT主要做码相位并行搜索，粗频率不是它自己算出来的，而是通过外层设置本地载波频率$ f_i $逐个搜索得到的；横块FFT本身不是用FFT估计粗频率，而是在某个粗频率假设下做码相位并行捕获。最终粗频率由本地载波频率$ f_i $决定，细频率由竖块FFT的$ m $决定，码相位由横块FFT/IFFT相关峰位置决定

$ \boxed{
\text{竖块 FFT}
\rightarrow
\left[
\text{粗频率循环}
\rightarrow
\text{细频率模块 }m
\rightarrow
\text{横块 FFT/IFFT 找码相位}
\right]
} $





直接对$ L\times N $的输入数据进行FFT捕获，就是把这Lms 的数据当成一整段长序列，对每一个多普勒频率假设做一次完整的FFT相关捕获，原始输入是L个1ms数据块：$ s(0),s(1),\cdots,s(LN-1) $，因为1ms内有N个采样点，所以总长度是：LN

假设搜索频率是：$ [-5\text{ kHz},+5\text{ kHz}] $，如果希望频率分辨率达到：$ \Delta f=\frac{1\text{ kHz}}{L} $，那么候选频率（搜索频点）就是$ \frac{10\text{ kHz}}{\frac{1\text{ kHz}}{L}}=10L
 $个



### 运算量分析
比较两种捕获方式的FFT运算量

+ $ \boxed{
\text{分块处理 + 竖块 FFT + 横块 FFT 捕获}
} $
+ $ \boxed{
\text{直接对 }L\times N\text{ 长数据做常规 FFT 捕获}
} $



N为每个1ms数据块内的采样点数，L为数据块的个数，这里数据块的长度均为1ms，那么就有L个1ms的数据块，总输入数据的长度为LN，假定多普勒搜索范围是：$ [-5\text{ kHz},+5\text{ kHz}] $，总宽度10kHz。<u>由于数据块的长度为1ms，那么本地载波搜索粗间隔固定为1kHz</u>。竖块FFT把每个1kHz的粗频率区间再细分成L个频率索引，对应的频率分辨率是$ \Delta f=\frac{1\text{ kHz}}{L} $，且用$ \operatorname{lb}(n) $表示$ \log_2(n) $，假设一个n点FFT的运算量约为：$ n\operatorname{lb}(n) $



分块处理方案的运算量主要是两大部分，第一个是竖块L点的FFT，第二个横块N点的FFT捕获

竖块FFT的原始数据排成$ L\times N $的矩阵，竖块FFT是固定i，沿着n方向做L点FFT，i是竖块索引，也就是列索引。因为i一共有N个，所以竖块FFT的次数是$ \boxed{
N\text{ 个 }L\text{ 点 FFT}
} $，每个L点FFT运算量近似为：$ L\operatorname{lb}(L) $，这部分的总运算量为：$ \boxed{
NL\operatorname{lb}(L)
} $

竖块FFT重排后得到L个横向块，每个横向块是1ms的总数据：$ Y(0,m),Y(1,m),\cdots,Y(N-1,m) $，其中$ m=0,1,\cdots,L-1 $，每一个m对应1kHz内的一个细频率索引。考虑粗频率搜索的范围是$ [-5,+5]\text{ kHz} $，本地载波粗频率间隔为1kHz，故有10个粗频率档，每个粗频率档内，把每一行数据做FFT，一行数据是N个点，做并行码相位捕获需要对这N个点做一次FFT，然后与预先存好的本地伪码+载波混合信号FFT结果的共轭做乘法（这部分的FFT已经提前算好并且存在RAM里，不计入实时运算量），再对乘法做一次N点IFFT，所以对一行上的1ms数据做一次并行码相位捕获需要做$ \boxed{
2\text{ 个 }N\text{ 点 FFT 等价运算}
} $。粗频率共10档，每个档位有L个横块，横块总共需要做$ \boxed{
10\times 2L\text{ 个 }N\text{ 点 FFT}
} $。每个N点FFT运算量是$ N\operatorname{lb}(N) $，所以横块FFT的总运算量是$ \boxed{
20LN\operatorname{lb}(N)
} $

分块处理方案的运算量=竖块FFT运算量+横块FFT运算量。即式4.84：

 $ \boxed{
C_{\text{Block}}
=
20LN\operatorname{lb}(N)
+
NL\operatorname{lb}(L)
=NL\left[20\operatorname{lb}(N)+\operatorname{lb}(L)\right]
} $





常规FFT的捕获方案把整个Lms，1ms内N点采样的数据看做输入长度为$ LN $的一整段数据，如果想在相同的多普勒频移假设$ [-5,+5]\text{ kHz} $内达到相同的分辨率$ \Delta f=\frac{1\text{ kHz}}{L} $，频点数为：$ \frac{10\text{ kHz}}{1\text{ kHz}/L}
=
10L $，故常规FFT捕获需要$ \boxed{
10L\text{ 个多普勒频率点}
} $

每个多普勒频率点，要对长度为LN的接收数据做一次FFT，然后和分块中横块FFT捕获中一样，和预先存好的本地伪码+载波混合信号FFT结果的共轭做乘法， 然后对长度LN的相乘结果做一次IFFT，故每个频点需要$ \boxed{
2\text{ 个 }LN\text{ 点 FFT 等价运算}
} $，总共需要做$ 10L\times2 $共$ \boxed{
20L\text{ 个 }LN\text{ 点 FFT}
} $。一个LN点的FFT运算量近似为$ LN\operatorname{lb}(LN) $，故$ C_{\text{Normal}}
=
20L\cdot LN\operatorname{lb}(LN) $。再利用对数的运算法则可得：$ \boxed{
C_{\text{Normal}}
=
20L^2N\operatorname{lb}(N)
+
20L^2N\operatorname{lb}(L)
} $



对比

$ C_{\text{Block}}
=
20LN\operatorname{lb}(N)
+
NL\operatorname{lb}(L) $

$ C_{\text{Normal}}
=
20L^2N\operatorname{lb}(N)
+
20L^2N\operatorname{lb}(L) $

 常规方案里主项带有$ L^2 $， 而分块方案主要带有$ L $

 分块方案把大问题拆成$ \boxed{
N\text{ 个 }L\text{ 点 FFT}
+
20L\text{ 个 }N\text{ 点 FFT}
} $，常规方案是$ \boxed{
20L\text{ 个 }LN\text{ 点 FFT}
} $





### 由于数据块的长度为1ms，那么本地载波搜索粗间隔固定为1kHz，可以这么理解吗？还是说2kHz或者说1kHz的整数倍都可以呢？  
$ \boxed{
\text{在这个算法结构下，因为数据块长度是 }1\text{ ms，所以本地载波粗搜索间隔自然取 }1\text{ kHz。}
} $ 

它不是随便规定的，而是由$ NT_s=1\text{ ms} $决定的



根本原因是竖块FFT只能分辨1kHz以内余频。竖块中相邻两个采样点相差$ NT_s=1\text{ ms} $，即竖向慢时间采样率为$ 1\text{ kHz} $，竖向FFT的频率周期为$ 1\text{ kHz} $。

每一个粗频率档位负责一个$ 1\text{ kHz} $宽的频率区间，例如$ [-5,+5]\text{ kHz} $可以分为$ [-5,-4),[-4,-3),\cdots,[3,4),[4,5) $一共10个1kHz区间；每个区间内部再由竖块FFT把L个采样点细分成L个频率索引：$ 0,\frac{1\text{ kHz}}{L},\frac{2\text{ kHz}}{L},\cdots,\frac{(L-1)\text{ kHz}}{L} $， 最终频率可以写成：$ \hat f=f_i+\frac{m}{L}\cdot1\text{ kHz} $。粗频率间隔取1kHz是为了配合竖块FFT的1kHz无模糊范围。

竖块FFT确实会把相差整数个1kHz的频率的起到的作用认为是一样的。因为$ e^{j2\pi(f+1\text{ kHz})n\cdot1\text{ ms}}
=
e^{j2\pi fn\cdot1\text{ ms}}e^{j2\pi n}
=
e^{j2\pi fn\cdot1\text{ ms}} $，所以差了几个1kHz就靠本地载波粗频率去枚举。如果粗频率间隔取2kHz，会漏掉一部分kHz档位。如果粗频率间隔取500Hz，每个粗频率档配合竖块FFT的1kHz余频范围，会出现重叠搜索。$ 0\text{ kHz} $档位覆盖$ [0,1)\text{ kHz} $，$ 0.5\text{ kHz} $档位覆盖$ [0.5,1.5)\text{ kHz} $，二者有重叠。

这样不是错误，但会增加计算量。除非有特殊目的，比如降低边界损失、提高鲁棒性，否则没有必要这么做。
