# GPS L1 C/A 手写练习

目标：先手写出 GPS L1 C/A 码的 PRN 1 序列。

先不要做载波、采样率、导航电文，只做 1023 个 chip 的扩频码。

## 你要先记住的规则

GPS C/A 码由两个 10 位移位寄存器生成：

- `G1` 初始状态：10 个 `1`
- `G2` 初始状态：10 个 `1`
- 每次循环生成 1 个 chip
- 一共循环 `1023` 次

`G1` 的反馈抽头：

- 第 3 位
- 第 10 位

`G2` 的反馈抽头：

- 第 2 位
- 第 3 位
- 第 6 位
- 第 8 位
- 第 9 位
- 第 10 位

PRN 1 使用 `G2` 的这两个输出抽头：

- 第 2 位
- 第 6 位

所以 PRN 1 的 C/A 码每一位是：

```text
ca_bit = G1第10位 XOR G2第2位 XOR G2第6位
```

## 抄写顺序

1. 新建 `ca_code_prn1.m`
2. 先写清空环境的三行：`clear`、`clc`、`close all`
3. 写 `G1` 和 `G2` 的初始状态
4. 写一个长度为 `1023` 的数组保存结果
5. 写 `for k = 1:1023`
6. 在循环里先取输出，再算反馈，最后移位
7. 循环结束后把 `0/1` 映射成 `+1/-1`
8. 画前 80 个 chip 看看

关键点：一定是“先输出，再更新寄存器”。
